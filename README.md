# Garden · веб-аудит кофеен

Garden теперь собирается как PWA без отдельного сервера: управляющий открывает ссылку на телефоне, входит под своим пользователем и проходит стандартный аудит. Ответы, фото, дата начала/окончания и автор сохраняются в памяти этого устройства.

Плановая ссылка после включения GitHub Pages:

```text
https://gardencoffeeapps.github.io/garden-inspections/
```

## Как это работает

- Один стандартный чек-лист для всех кофеен: 12 разделов, 136 вопросов, 10 обязательных фото.
- В справочнике заведены реальные кофейни Garden.
- Каждый управляющий входит под своим логином и видит только привязанные к нему кофейни.
- Ответы Да/Нет; при Нет обязателен комментарий.
- Фото требуются только у критических вопросов и делаются камерой в приложении.
- После завершения обход блокируется от редактирования внутри приложения.
- Руководительский вход показывает результаты, которые есть на этом же устройстве.

Без сервера данные не собираются автоматически со всех телефонов в один общий кабинет. Для централизованной истории по всем управляющим позже понадобится сервер, таблица/форма приёма отчётов или другой общий канал выгрузки.

## Инструкция для управляющих

Короткая инструкция для запуска, входа, прохождения обхода и действий при ошибке связи: `docs/manager-instruction.md`.

## Запуск локально

```sh
pnpm install --frozen-lockfile
pnpm build:web
```

Готовая веб-версия появится в `dist/`. Для быстрой проверки можно открыть её любым статическим локальным сервером. Камера на телефоне обычно требует HTTPS; GitHub Pages даёт HTTPS автоматически.

## Публикация

В репозитории есть GitHub Actions workflow `.github/workflows/pages.yml`. После push в ветку `main` он:

1. устанавливает Node.js 24 и pnpm;
2. собирает веб-версию командой `pnpm build:web`;
3. публикует каталог `dist/` в GitHub Pages.

Если Pages ещё не включён, в настройках репозитория выберите GitHub Pages с источником GitHub Actions. После успешного workflow ссылка будет доступна в разделе Actions/Pages.

## Структура

```text
App.tsx                         Интерфейс управляющего и руководителя
src/api.ts                      Локальная авторизация и localStorage-хранилище
src/types.ts                    Модели данных
shared/checklist.json           Согласованный чек-лист
shared/cafes.json               Справочник кофеен Garden
public/                         PWA-манифест, иконки, регистрация service worker
scripts/build-pwa.mjs           Подготовка dist для GitHub Pages
.github/workflows/pages.yml     Автосборка и публикация GitHub Pages
docs/checklist-source.md        Исходная согласованная редакция чек-листа
```

Серверная папка оставлена как прежний вариант для будущей централизованной версии, но текущий основной сценарий работает без неё.
